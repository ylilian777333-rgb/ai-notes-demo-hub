笔记产品方案

2026.05.26 · 杨李莲

一、产品定义

笔记 = 用户信息记录的综合性功能，最终产出用户可直接消费的内容形态。

不是单纯的文字记录工具，也不是知识库。它是一个让用户形成具象功能心智的产品——用户知道它能产出课堂笔记、会议纪要、待办、播客、PPT。

用户心智

类比：用户认为 ChatGPT 是"翻译官"——这是具象的功能心智。笔记也需要这样的具象认知：

  • 它帮我上课 → 产出考点、出题、复习播客
  • 它帮我开会 → 产出纪要、待办、会议PPT
  • 它帮我记事 → 产出待办、提醒、知识卡片

核心逻辑

用户 写/说/拍
笔记沉淀（中间态）
AI 理解加工
产出最终消费物（终态）
用户直接使用

关键认知：笔记正文是中间产物。AI生成的笔记和收藏内容越多，用户直接阅读原始笔记的频率越低。用户真正打开的是终态消费物——播客点了就听、PPT打开就分享、考点拿来就复习。

二、最终消费物清单

产品围绕 7 种最终消费物设计。每种都是用户可直接使用的终态内容。

最终消费物 从什么笔记产出 怎么触发 用户怎么消费
考点清单 课堂录音笔记 AI对话框 "提炼考点" 打开直接复习，结构化知识点
模拟题 课堂录音笔记 AI对话框 "出题" 做完检验掌握度，错题标记
待办事项 会议 / 课堂 / 速记 AI自动提取 或 手动触发 直接执行，到期提醒，同步日历
播客 任何笔记 AI对话框 "生成播客" 点了就听，上车播/闹钟后播
PPT 会议 / 任何笔记 AI对话框 "做PPT" 打开直接分享、讲解
知识卡片 跨篇聚合 AI对话框 "生成卡片" 一张卡说清一件事，可分享
脑图 课堂 / 任何笔记 AI对话框 "生成脑图" 看结构，快速回忆知识框架

三、内容结构：原文 vs 产出物

每篇笔记内部，明确区分三层内容：

原文
原始内容（录音转写 / 截图 / 用户手写）
用户手动记录或系统录入的原始数据。录音带时间线，照片带时间戳。这是笔记的"素材层"。
正文
笔记正文（AI整理后的结构化内容）
如：课堂总结的知识点列表、会议纪要的议题和结论。AI加工后的结构化文本，是用户日常阅读的主体。
消费内容卡片
最终消费物（考点 / 播客 / PPT / 待办 / 脑图）
基于正文经AI二次创作后生成的可直接消费内容。每个卡片可独立打开使用。放在页面底部，保证与现有笔记页面视觉一致性。

为什么这个顺序：保持与现有笔记详情页的视觉一致性。用户打开笔记首先看到的仍然是内容本身（原文+正文），消费内容卡片在底部作为"基于这篇笔记，AI帮你做了什么"的延伸——逻辑自然、不突兀。

产出物与笔记的关系：

  • 产出物挂在对应笔记内（详情页底部卡片区）
  • 同时聚合到侧边栏（全局可查，跨笔记浏览）
  • 产出物可独立打开、独立操作（播放/做题/分享），不需要回到笔记原文
  • 产出物标注来源笔记，用户随时可追溯

四、交互形态

4.1 详情页结构

用户打开一篇笔记，从上到下看到的是：

层级（从上到下）内容用户行为
标题区笔记标题 + 时间 + 来源标记知道这是什么
原文区录音播放条 / 原始手写 / 照片回听录音、查看素材
笔记正文AI整理后的结构化内容（总结/纪要/知识点）日常阅读的主体
消费内容卡片已生成的终态消费物（考点/播客/PPT/待办）点击直接使用
AI对话框（底部固定）"生成播客、出题、做PPT..."触发新的产出物生成

4.2 AI对话框 = 产出物生成入口

保持现有交互模式——笔记底部的AI对话框。用户在这里触发所有产出物的生成：

  • 点击输入框 → 弹出智能推荐chip（提炼考点 / 生成播客 / 做PPT / 提取待办 / 生成脑图 / 问问题）
  • 用户点击chip或自由输入 → AI基于当前笔记内容生成对应产出物
  • 生成完成 → 产出物卡片出现在详情页上方 + 同步到侧边栏

4.3 侧边栏分类逻辑

侧边栏三段式设计，每段回答一个独立问题，逻辑不混用：

笔记来源

回答：我有多少笔记、从哪来的

  • 全部
  • 我的创作
  • 录音笔记
  • AI速记

AI帮你做的

回答：AI从我的笔记里产出了什么

  • 待办
  • 播客
  • PPT
  • 考点 / 出题
  • 知识卡片
  • 脑图

文件夹

回答：我怎么组织我的笔记

  • 高等数学
  • 产品工作
  • 投资理财
  • 个人
  • + 新建文件夹

侧边栏与首页的对应关系：

侧边栏段落点击后看到什么与首页的关系
笔记来源对应类型的笔记列表= 首页筛选tab的维度
AI帮你做的所有笔记产出的该类型消费物列表= 跨笔记聚合视图
文件夹该文件夹下的笔记列表= 首页文件夹图标点开后的分类

分类逻辑原则：三段之间不混用。文件夹只管笔记本身，不管产出物；产出物跨所有笔记聚合，不受文件夹限制。一篇笔记只属于一个文件夹（文件夹逻辑，非标签逻辑）。

五、首页设计

首页保持现有笔记列表框架不变。唯一新增：每张笔记卡片底部标注已生成的产出物标签。

元素内容作用
标题栏"笔记" + 编辑/更多图标不变
搜索栏搜索不变
筛选tab文件夹图标 + 分类pill（全部/会议/课堂/生活...）不变
笔记卡片标题 + 摘要 + 产出物标签 + 时间/来源新增产出物标签
底部栏附件 / 录音 / 新建不变

产出物标签的作用：用户扫一眼首页列表，就知道"这篇笔记已经帮我准备了什么"——哪篇有考点、哪篇有播客、哪篇有待办。不需要打开才发现。

六、完整消费链路（以课堂笔记为例）

阶段用户做什么系统做什么产出什么
课中录音 + 拍照实时转写 + 照片关联时间线—（数据积累中）
课后无需操作AI生成结构化课堂笔记 + 提取待办课堂笔记正文 + 待办
复习打开笔记 → 点"提炼考点"AI基于全文提炼知识点考点清单
做题点"出题"AI基于考点出模拟题模拟题
通勤点"生成播客"AI将内容音频化播客（点了就听）
汇报点"做PPT"AI将内容转为演示文稿PPT（打开就分享）

每个阶段的产出物都是终态——用户拿到就能直接用，不需要再加工。这就是"消费链路完整"的含义。

七、产品定位

自增长可赋能的个人数字资产中枢

关键词含义
自增长用户每次记录 + 系统自动采集，数据持续积累，AI对用户的理解不断加深
可赋能AI基于积累产出7种用户可直接消费的最终内容
中枢用户侧是创作和消费的入口，MiClaw侧是调用全量数据的底座

飞轮：记录越多 → AI越懂用户 → 产出越精准 → 用户越愿意记 → 记录越多
