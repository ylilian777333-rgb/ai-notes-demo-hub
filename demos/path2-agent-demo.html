❌ 定位说不清

"收集 → 整理 → 消费"描述的是一个能力，不是一个产品。这个能力可以嵌到笔记里、widget 里、小爱里——不需要一个独立的壳。

06 / 08
但方向本身有想象空间

人车家 Agent 会产生现有 App 管不了的新数据

真实的空缺

跨设备、跨场景、跨时间的数据——不归日历、不归相册、不归笔记。开车时的灵感、耳机里听到的要点、手表上的快速记录，这些数据今天确实没有一个统一的归宿。

核心问题

一定要有一个用户愿意专门来用的具象功能，这个 App 才能成立。小爱记忆、知识库这些概念不是具象功能，用户不知道来了能干什么。

这个功能是什么？是接下来要重点探索的课题。

07 / 08
整体判断

两个方向不是二选一

当前选路径一落地，未来两个方向可以同时存在，各自解决不同的问题

当前 · 推荐

路径一：归笔记

同类内容在一起，合集素材完整。笔记从"帮用户记"升级到"帮用户记 + 帮用户用"。笔记是沉淀层，小爱和系统触点是触达层。

未来 · 探索

路径二：系统 Agent

人车家会产生现有 App 管不了的新数据，方向有想象空间。核心是找到那个独特的产品功能——目前是能力不是产品，需要找到独特的打开理由。
