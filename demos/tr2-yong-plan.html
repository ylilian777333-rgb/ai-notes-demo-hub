OS5「用」做什么

从 5 场景机会点抽出 3 件要做的事：
A
一句话取回，带出处
跨多篇取回相关内容，答案能定位到原文；找不到就说没有，不用无关内容拼凑
覆盖场景
翻回同主题、查历史客户、找证件与账目
B
一键出产出物，格式规整能直接发出去
按品类给一个默认产出，不让用户选模型选模板；合计算好、版式规整、导出不错位
五类产出物
成长记录合集、指标趋势、掌握度报告、报价汇总单、主题复盘
C
结果自动分发，不用打开笔记
识别出的事进待办中心与日历，可点卡片连到系统能力；经授权内容可被系统与三方读取
分发去向
待办中心、日历、拨号与通讯录、导航、经授权对外调用

B 一键出产出物 · 五类产出物规格

每类产出物都要写清：输入是什么、产出长什么样、能不能回溯、结果去哪
产出物输入产出规格回溯结果去向
成长记录合集
 某主题下全部记录（文字 / 照片 / 录音） 网页版，按月分段，每段一句概述 + 当月记录，带原图与原声 每段「来自 3 条记录」可展开跳回 分享链接（可设有效期）/ 长图 / PDF
指标趋势
 历年体检报告图片中抽出的指标 折线图 + 数值表，带参考区间；图下只写事实，不给健康建议 每个数据点对应一张源报告 导出图片（敏感项默认打码）
掌握度报告
 一门课的笔记抽出的考点 + 口述作答 讲清了什么 / 没提到什么逐条列出，不给分数 每个考点可回到源笔记原句 复习安排进待办与日历，到点直接打开该题
报价汇总单
 一个项目下带数量的记录 + 单价 逐行明细 + 小计 + 总计，抬头含客户与联系方式；没填单价的行标出来 每行可跳回源笔记；总计由明细算出 导出 PDF / 分享图，导出前做一致性校验
主题复盘
 同主题的零散想法（跨月） 想通了什么、还卡在哪，指出反复出现的同一处 每条结论可展开到原始那几条想法 存为笔记，可分享
