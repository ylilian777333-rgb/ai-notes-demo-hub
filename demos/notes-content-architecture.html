01
产品定义
一句话定义
笔记 = 用户的记录 + AI 帮你把记录变成可直接消费的内容
用户负责"喂内容"，AI 负责让这些内容变得能用
02
内容层级 · A原文 → B中间态 → C最终产物
A · 原文
用户输入 / 系统采集
📝 笔记（有内容体）
✍️ 手写笔记   🎤 录音/会议
📷 图文记录   📞 通话录音
⌚ 穿戴录音

⚡ 记忆（碎片条目）
🔗 链接   🪪 卡证   📍 地址

💡 用户手写的感想/图文
本身就是最终产物
→
AI理解+生成
B · 中间态
AI加工，还需转化
AI 生成但用户不会反复看

会议纪要 → 还需变成待办
课堂笔记 → 还需变成考点
通话纪要 → 还需提取行动项
穿戴摘要 → 还需去口语化/扩写
链接摘要 → 还需整合为播客

拿到后下一步还要做事 = 中间态
→
再加工
C · 最终产物
用户直接消费
拿到就能用，不需要再做任何事

🎙️ 播客 — 点了就听
📊 PPT — 打开就讲
✅ 待办 — 到期提醒执行
🃏 知识卡片 — 一张说清一事
🧠 脑图 — 看结构快速回忆
📝 考点/模拟题 — 直接复习
❓ 问答
不是产出物，是贯穿 B 和 C 的能力层 — 笔记/记忆/产出物里的信息，问了就能答
贯穿 B + C
⚖️ 判断标准
用户拿到后下一步是什么？还要再做事 = 中间态 ｜ 点了就用 = 最终产物
