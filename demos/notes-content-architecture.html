01
产品定义
一句话定义
笔记 = 用户的记录 + AI 帮你把记录变成可直接消费的内容
用户负责"喂内容"，AI 负责让这些内容变得能用
02
内容层级 · A原文 → B中间态 → C最终产物
A · 原文
用户输入 / 系统采集
📝 笔记（有内容体）
✍️ 手写笔记   🎤 录音/会议
📷 图文记录   📞 通话录音
⌚ 穿戴录音

⚡ 记忆（碎片条目）
🗣️ 语音记忆   📱 识屏记忆
🔗 链接收藏

💡 用户手写的感想/图文
本身就是最终产物
→
AI理解+生成
B · 中间态
AI加工，还需转化
AI 生成但用户不会反复看

会议纪要 → 还需变成待办
课堂笔记 → 还需变成考点
通话纪要 → 还需提取行动项
穿戴摘要 → 还需去口语化/扩写
链接摘要 → 还需整合为播客

拿到后下一步还要做事 = 中间态
→
再加工
C · 最终产物
用户直接消费
拿到就能用，不需要再做任何事

🎙️ 播客 — 点了就听
📊 PPT — 打开就讲
✅ 待办 — 到期提醒执行
🃏 知识卡片 — 一张说清一事
🧠 脑图 — 看结构快速回忆
📝 考点/模拟题 — 直接复习
❓ 问答 — 贯穿 B 和 C 的能力层，不是产出物，是消费方式

判断标准

用户拿到后，下一步动作是什么？如果下一步是"再做点什么"，它就不是最终态。
播客 = 点了就播 ✅ ｜ 会议纪要 = 还需要变成待办 ❌ ｜ 通话纪要 = 还需提取行动项 ❌

03
A层 · 两个物理容器
所有用户内容只落两个地方，按物理位置区分：在笔记APP里的是笔记，在小爱记忆里的是记忆。

📝 笔记 — 笔记APP内，首页可见

  • ✍️ 手写/键入笔记（用户主动创建）
  • 🎤 录音笔记 — 会议/课堂/随身
  • 📷 图文笔记 — 照片+文字记录
  • 📞 通话笔记 — 挂断后自动生成 NEW
  • ⌚ 穿戴笔记 — 戒指/手表录音 NEW

⚡ 记忆 — 小爱体系内，不进首页

  • 🗣️ 语音记忆 — "帮我记一下..."
  • 📱 屏幕记忆 — AI键识屏（身份证/地址）
  • 🔗 链接收藏 — 外部APP点收藏存入
04
C层 · 产出物清单
待办在内容层级上与播客/PPT同级，但入口保持在首页右上角（用户习惯）。
🎙️
播客
任何笔记/多条收藏 → "生成播客" → 点了就听
场景：通勤、运动、做饭时
📊
PPT
会议/笔记 → "做PPT" → 打开直接分享、讲解
场景：汇报、分享、对齐
🧠
脑图
任何笔记 → "生成脑图" → 看结构，快速回忆
场景：复习、理清思路
✅
待办
会议/通话/语音 → AI提取或手动触发 → 到期提醒执行
场景：执行跟进
入口：首页右上角
📝
考点清单 / 模拟题
课堂笔记 → "提炼考点"/"出题" → 直接复习
场景：期末复习、知识检验
🃏
知识卡片
跨篇聚合 → "生成卡片" → 一张说清一事
场景：记忆、分享、速查
❓
问答 — 不是产出物，是贯穿 B（中间态）和 C（产出物）的能力层。笔记里的、记忆里的、产出物里的信息——问了就能答。
贯穿 B + C
