00
产品定义 · 笔记是什么
一句话立住定位，再补两个特点、划清边界，最后一条飞轮把它转起来
定位
笔记 = 你主动沉淀、看得见、改得动的个人内容层。你决定存什么；AI 帮你把它理好、随时找出来用，还会主动找你——内容越攒越多，越用越懂你。
✦

会主动不只被动记录

该看的内容主动浮现、到期主动提醒；笔记还能被小爱调用，回答、写作时引用你存过的内容——从"等你来翻"变成"主动帮你"。

⇄

跨端一份内容，随处记随处调

手机 / 手表 / 车机 / 耳机 / 平板，哪个顺手用哪个记；任意设备都能把内容调出来用；多端一份、跨端接力，在每块屏之间自己跑。

笔记做用户主动存的、看得见、改得动的个人内容；把它结构化、可检索、能被调用，也会主动浮现。
笔记不做不做隐式行为画像 / 后台黑盒记忆；不默认全收——用户主动挑有价值的内容存进来。

01
从定义到场景 · 5 个明星场景
每个场景都跑通"随处记 → AI 理好 → 沉进内容层 → 用得上 / 主动服务"这条闭环
五个不是五个功能，而是同一条飞轮在五个场合的显化。共同点：随处记（跨端）+ AI 主动理好、主动找你 + 内容沉淀下来越用越懂你。
01
开会办公 · 散会即得
开完会最烦回工位再整理一遍——纪要、待办、给老板的汇报都得重弄。
手机
占位桌上一放开录
一键开录：手机往桌上一放，免耳机、免唤醒
→
手机
占位自动纪要+待办
散会自动出纪要+待办：结论/分工/责任人/deadline
→
手机
占位一句话生成汇报
一句话成汇报：对小爱说一句，纪要直接变 PPT
→
手表
占位到点提醒
认领的事进日程：到点手表主动提醒
→
车机
占位路上听要点
路上听 AI 串好的要点：开车不看屏
价值：要的不是"录音转文字"，是"散会活就办完了"——纪要一份，手机记录、手表提醒、车机播报，跨端接力。
飞轮 · 写得出 + 用得上⚠ 边界：与生产力赛道对齐
02
上课学习 · 一份内容，看 / 听 / 练随场景切换
平板记的、路上想复习的、睡前想练的，是同一份东西，别让我来回倒腾。
平板
占位手写+录音
手写+录音对齐：手写字和老师讲的话同一份
→
手机
占位复习大纲+考点
下课自动出大纲+考点：一节课重点即理好
→
耳机
占位通勤听播客
笔记转播客：通勤路上把这章听一遍
→
手机
占位睡前做题
AI 出几道题：睡前当场练，知识点不丢
价值：一份课堂内容在多屏之间"自己变形"，看听练不断档；大纲 / 播客 / 题目是内容攒下来后的下游价值。
飞轮 · 用得上 + 自己长
03
看病陪诊 · 个人健康档案
医生说得太快、报告一堆记不住，下次复诊翻半天找不着上次的。
手机
占位录医嘱+拍报告
AI 键一按边问边录：医嘱、报告一起收进来
→
手机
占位自动健康档案
自动汇成健康档案：症状/诊断/用药/复诊时间
→
手表
占位吃药提醒
吃药/复诊主动提醒：到点手表提醒，不漏
→
手机
占位复诊一键调出
复诊一句话调出上次记录：给医生看，接得上
价值：把零散就诊变成一条连续、随时能调出来的个人健康档案——越积累越贴合、越难替代。
飞轮 · 收得进 + 自己长⚠ 边界：与运动健康·体检档案对齐
04
出行旅游 · 出发前汇入各处信息，玩完就是一份完整攻略笔记
攻略散在小红书、群聊、订单、地图收藏里，玩完还得自己整理成能用能分享的一份。
手机
占位各来源一键收
出发前各处信息汇入：小红书种草 / 机酒订单 / 地图收藏 / 群里攻略，一键收进同一篇
→
手机
占位AI 汇成攻略笔记
AI 汇成一份攻略笔记：行程单 + 必去 + 必带 + 预算，出发前就成型
→
多端
占位玩当中随手补
玩当中随手补进同一篇：新发现、照片、花费自动归位
→
手机
占位完整攻略笔记
玩完即成一份完整攻略笔记：可复用、可分享，不用再回头整理
价值：把散在各处的攻略信息汇成结构化的一份，边玩边补——出发前有攻略、玩完即成一份完整可分享的攻略笔记，全程不用手动整理。
飞轮 · 收得进 + 用得上⚠ 边界：与日程出行 / 影像对齐
05
