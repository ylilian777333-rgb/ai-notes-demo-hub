先立住笔记是什么，再讲要做的场景

OS5 是小米第一代 Agentic OS——AI 从"问答框"走向"Agent 化主动服务"，并做多设备 AI 强互联。在这条主线里，笔记 = 用户的个人内容层，也是内容领域的垂域 Agent：你主动沉淀、看得见改得动的内容，既能被小爱 / MiClaw 主 Agent 调用，也能主动感知场景、把该看的内容和服务推到你面前，还能一份内容跨端随处记、随处调。下面 5 个明星场景，都是这条定义的闭环显化。（场景配图为占位，Figma 稿后续填入）

产品定义 · 笔记在 Agentic OS 里是什么
一句话立住定位，补上 Agentic 与跨端互联两个维度，划清边界，再讲飞轮和与主 Agent 的关系
笔记 = 用户主动沉淀、看得见改得动的个人内容层，也是内容领域的垂域 Agent。它承接"内容"这一层——主 Agent（小爱 / MiClaw）要真正懂你、能基于你的积累办事，就需要这样一层用户认可、可管理、且能被调用的个人内容。
✦ 维度一 · Agentic

从"被动记录"到"主动服务"

笔记不只等你翻——主动感知（写相似主题 / 到某地 / 提到某人时浮现相关内容）、主动服务（到期提醒、生成服务卡片），并把检索 / 写入 / 关联能力 tools 化，作为内容垂域 Agent 被主 Agent 编排调用。

对齐 OS5：AI 从"输入框交互"升级为"AI 主动推荐交互"（服务卡片 / 双击 AI 键协作）。
⇄ 维度二 · 跨端互联

一份内容，随处记、随处调

手机 / 手表 / 车机 / 耳机 / 平板，哪个顺手用哪个记；任意设备让小爱调出内容、一句话操控；内容多端一致、跨端接力，在每块屏之间自己跑。

对齐 OS5：AI 强互联——多设备 AI 体验统一（唤醒 / 视觉 / 任务执行 / 数据调用）。
笔记做

用户主动存的、看得见、改得动的个人内容；把它结构化、可检索、tools 化，供主 Agent 调用、也能主动浮现。用户决定存什么，一键存、随时改。

笔记不做

不做隐式行为画像 / 黑盒系统记忆（主 Agent 系统侧负责）；不默认全收——口径是用户主动挑有价值的内容存进来。

Agentic
和主 Agent 的关系：小爱 / MiClaw 是主 Agent（对话、编排、办事），笔记是内容垂域 Agent + 个人内容层（沉淀、供给、主动浮现）。内容存得越多，主 Agent 越懂你、办事越贴合——这正是 Agentic OS 里"内容"这一层不可替代的位置。

从定义到场景 · 5 个闭环明星场景
每个场景都跑通"采集 → AI 加工 → 沉淀进内容层 → 被主 Agent 调用 / 主动服务"，且跨端闭环
五个场景不是五个功能，而是同一条飞轮在开会、上课、看病、出行、灵感五个场合的闭环显化。每个都同时踩中 OS5 的两条主线：Agentic 主动服务 + 跨端互联；竞争力落在系统级（免唤醒 / AI 键 / 跨端接力）与越用越懂你（内容沉淀 + 主 Agent 调用），最终牵引 NSS。

收口 · 一句话
定义先行：在 Agentic OS 里，笔记是主 Agent 可调用的个人内容层 + 内容垂域 Agent。五个闭环明星场景，是这条定义在开会、上课、看病、出行、灵感里的显化——随口记（跨端）→ AI 理好 → 沉进内容层 → 被主 Agent 调用 / 主动服务，越用越懂你，牵引 NSS。
