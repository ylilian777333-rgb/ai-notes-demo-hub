      说完，就是一篇好笔记
      • 📄 PPT 文案
        主标题：说完，就是一篇好笔记
        副标题：放着录，AI 帮你整理成能直接用的一篇
        🎤 口播
        今天先讲笔记。过去记笔记，是你自己一个字一个字敲；现在你只要说完，它就是一篇能直接用的笔记——不是一堆转写文字。〔转场〕它凭什么能省掉你敲字？先看一个每天都在发生的场景。
        🖼 页面
        满屏主张。大字主标题居中 + 一行副标题；不放手机、不列功能点，大量留白，先立态度。
        • 📝 备注
          开场只立主张、不讲功能（对应李楠“从用户结果出发、不做功能罗列”）。10 秒内带过，快速进入场景。
    • P02
      记笔记，不该让你分心
      • 📄 PPT 文案
        主标题：记笔记，不该让你分心
        对比标签：过去 · 自己敲字 ／ 现在 · 语音速记
        🎤 口播
        开会、上课、看病，你一边要听、一边要记，顾着记就跟不上，回头还得重新整理。我们想做的很简单：放着录就行，说完自动整理成一篇，重点、待办都在。〔转场〕先从最常见的开会说起。
        🖼 页面
        左右两台真机对比——左“过去 · 自己敲字”（打字键盘界面），右“现在 · 语音速记”（录音波形界面）。用真机截图，不用文字讲变化。
        • 📝 备注
          讲“为什么做”，用真实痛点（分心、跟不上、回头整理），不贬低任何竞品。对应李楠“先说清为什么 + 界面前后对比”。
    • P03
      开完会，一份能直接用的会议纪要
      • 📄 PPT 文案
        主标题：开完会，一份能直接用的会议纪要
        清单：议题分点 · 结论拎出 · 待办落到人和时间 · 关键数字与决策不漏
        🎤 口播
        开完会你拿到的不是一长段流水账，而是一份能直接用的纪要：议题分好点，结论单独拎出来，最重要的是——每一条待办都落到了人、落到了时间。为了这一点，我们针对会议场景反复调过 prompt，确保待办不漏、责任到人。〔转场〕换个场景，上课也是一样的道理。
        🖼 页面
        左“好的会议纪要”勾选清单；右手机纪要界面（会议标题+时长、核心结论区、待办区每条带负责人头像+日期）。待办的“负责人 + 时间”高亮。
        • 📝 备注
          核心页。要点出“什么是好的会议纪要”+“我们为做好它调了 prompt”（李楠最看重：讲好的标准 + 为好做了什么）。“待办到人到时间”是差异点，重点讲。用真实验收过的会议案例。
    • P04
      下课后，一份能拿来复习的课堂笔记
      • 📄 PPT 文案
        主标题：下课后，一份能拿来复习的课堂笔记
        清单：理成知识点 · 标出考点 · 附例题解析 · 复习直接能用
        🎤 口播
        上课不用一边听一边记、打乱思路。下课后，它把老师讲的理成知识点，还帮你标出考点、附上例题解析——复习的时候直接就能用。〔转场〕再看一个更需要“记准”的场景：看病。
        🖼 页面
        左“好的课堂笔记”清单；右课堂笔记界面（知识点分点、考点高亮标签、例题解析折叠区）。
        • 📝 备注
          考点 / 例题是“好”的关键要素，普通转写做不到。需真实课堂录音验收过的案例。学习场景，覆盖学生用户。
    • P05
      看完病，医生交代的一条没落
      • 📄 PPT 文案
        主标题：看完病，医生交代的一条没落
        清单：诊断 · 用药（药名/剂量/天数）· 注意事项 · 复诊时间
        🎤 口播
        看病最怕漏。医生说的诊断、用什么药、吃几天、什么时候复查，一条落下都可能出问题。我们分析了就诊时医生通常会交代什么，专门为这个场景做了优化：诊断、用药方案、注意事项、复诊时间，回家照着做就行。〔转场〕“记好”已经做到了；记好之后你往往还想改它、接着写——这时候，笔记本身就能帮你。
        🖼 页面
        左“好的就诊记录”清单；右就诊记录界面（AI 总结区、检查结果、用药方案带剂量、复查安排带日期）。用药和复诊时间高亮。
        • 📝 备注
          李楠亲点的医嘱例子。强调“分析了医生会交代什么 → 专项优化”。口径注意：只如实记录医生所说，不生成诊断 / 用药建议，避免过度承诺与医疗风险。
    • P06
      打开一篇笔记，随时召唤超级小爱
      • 📄 PPT 文案
        主标题：打开一篇笔记，随时召唤超级小爱
        副标题：选中就改，接着就写，不用复制到别处
        🎤 口播
        打开任意一篇笔记，超级小爱就在里面。选中就改，接着就写，都在这一篇里，不用复制到别处。〔转场〕先看最常用的一件事：改。
        🖼 页面
        居中一篇笔记界面，底部“问问超级小爱”输入条，旁边“改写 / 续写 / 生成脑图”快捷入口。
        • 📝 备注
          AI 笔记引子、语音 → AI 的转场页。落点是“就在这一篇里、不跳出去”，不铺功能清单。对应李楠“不罗列功能”。
    • P07
      随手记的一句话，改成能直接发的通知
      • 📄 PPT 文案
        主标题：随手记的一句话，改成能直接发的通知
        前后对比：口水话 → 正式通知（已替换回原文）
        🎤 口播
        周会上你随手记了句大白话，会后要发群里又得重写。选中这句，让小爱改一下——它会按“通知”的语气改得得体、完整，直接就能发出去。〔转场〕改是把已有的改好，那如果只写了个开头呢？
        🖼 页面
        左右前后对比——左“随手记下”（口水话原句），右“改成正式通知”（得体完整版），底部标“✓ 已替换回原文”。
        • 📝 备注
          改写要贴“通知”这个场景语气，不是泛泛润色（这才是“好”）。用界面前后对比呈现，别用文字讲变化。

      列了几条提纲，补成完整发言稿
      • 📄 PPT 文案
        主标题：列了几条提纲，补成完整发言稿
        前后对比：提纲几条 → 完整发言稿（已补充到笔记）
        🎤 口播
        老师开家长会，先列了几条要点。小爱顺着这几条，补成一篇能照着念的完整发言稿——语气、结构都到位。〔转场〕内容多了、笔记长了，复习又是另一个场景。
        🖼 页面
        左“发言提纲”（几条要点），右“完整发言稿”（补全后的段落），底部标“✓ 已补充到笔记”。
        • 📝 备注
          续写基于笔记已有要点续写、不是凭空生成（可控、贴合）。家长会是生活场景，平衡前面的职场例子。
    • P09
      考前复习，长笔记先理成脑图
      • 📄 PPT 文案
        主标题：考前复习，长笔记先理成脑图
        示意：长笔记 → 脑图（已插回笔记）
        🎤 口播
        一整篇课堂笔记，考前想快速过一遍。让小爱理成脑图，章节、知识点、考点之间的关系一眼看清，脑图还能直接插回笔记里。〔转场〕最后，把这一趴收回来。
        🖼 页面
        左一整篇长课堂笔记，右理成的脑图（根：供需与均衡；分支：需求曲线 / 供给曲线 / 均衡价格 / 考点例题），标“✓ 已插回笔记”。
        • 📝 备注
          需确认脑图是本次真实交付、“插回笔记”能力已验收，否则降级或换能力，避免讲了做不到。
