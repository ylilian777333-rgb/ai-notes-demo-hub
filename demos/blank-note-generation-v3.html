空白笔记 0→1：帮用户写出第一篇能用的笔记

用户打开一篇空白文字笔记，常常对着白板不知从哪下手；而我们的 AI 又全藏在二级页，只打字、不用语音的人，几乎碰不到它。本稿只解决一件事——在不切页面的前提下，顺着用户已经写的，帮他最快写出第一篇能用的笔记。
这不是交互优化：第一篇是后面一切内容的起点，也是笔记区别于通用 AI 的入口。下面讲清三件事：为什么是我们能做、进来时怎么帮、做没做好怎么衡量。

核心判断
先抛判断：0→1 不是体验优化，是整个内容飞轮的发动机
笔记的胜负手不在"记得下"，在"写得出"。第一篇都生不出来，后面承接 MiClaw 的内容、做 PPT / 播客 / 网页，全是空的。谁先帮用户把第一篇写出来，谁就拿到内容入口。
病根

AI 藏在二级页

想用 AI 得先点小星星、进对话框。只打字、不用语音的用户，打开空白笔记几乎碰不到 AI。

赌注

第一篇 = 下游的前提

PPT、播客、网页都是拿"已有内容"再加工。没有第一篇，下游全是空转。

打法

边写边帮，不切页面

没写给起手式帮你开始，写了看你写了什么帮你写下去、改好。点一下就用上。

01
为什么是我们 · 护城河
先回答最该被问的：豆包也能帮你写，凭什么用我们
通用 AI 也能帮你写。但它写不出"你的"那一篇——因为它没有你的料。而我们手上，恰好有一份别人复制不了的料。
进来的料具体是什么通用 AI 能拿到吗用来写好哪一面
内容素材同主题历史笔记 / 文档、录音 & 通话转写、播客 / PDF / 网页、图片 OCR拿不到有料、有据
个人背景小爱记忆（你是谁 / 角色 / 偏好）、写作习惯、项目与协作关系拿不到像你、贴合你
此刻情境时间 / 地点 / 日程 / 最近活动拿不到对得上场景
记得越多，写得越像你，越离不开。这正面回答了"为什么这些内容都要沉淀进笔记"——不是建仓库，是攒"把你这篇写好"的料；这些料端侧独有、是护城河。
先撬动哪块

P0：最高频、强相关

同主题历史笔记 + 小爱记忆 + 录音转写。P1 播客 / PDF / 网页（按需）；P2 图片 OCR / 情境信号（长尾）。

本质

存得相关，不是存得多

料进来只是第一步，得能被检索到、和这篇相关才有用——堆一堆检索不到的料，对写作零贡献。

02
服务谁 · 文字笔记用户
断言式划清：这份不和语音抢，补的是被冷落的一大块；再回到真实的人
语音是主入口。但不是所有人、所有场合都能开口——开会、地铁、深夜、习惯边想边打字的人，是现在被冷落的一大块。这份补的就是这块。

03
解法 · 一条规则、三个时机
不堆功能：一条规则贯穿，AI 在三个时刻分别帮，全程不切页面
分水岭只有一个：你写了没有。没写——给起手式，帮你开始；写了——工具条看你写了什么，帮你写下去、改好。四种情况，就这一条规则。

手上：贴了一段 / 写完一段

04
把这篇写好 · 你的资料怎么被用上
护城河怎么落地：AI 一边引用你的资料（有据），一边用你的背景（像你）
把一篇写好，靠两件事一起：一边引用你的资料让它有据（检索引用），一边用你的背景让它像你（背景注入）。只引用不懂你，像拼凑的资料；只懂你不引用，像空谈——两样合起来，才是别人复制不了的"你的"那一篇。
资料怎么被找到：相关性怎么算（不是随便引）
取这篇笔记开头约 500 字当查询，AI 搜索做"主题层面的语义相似度"匹配，返回候选 + 相关性分数，按分数取用。复用现有 AI 搜索能力，不新造一套。
相关性分数怎么处理
> 0.9确定关联，直接用
0.8 – 0.9强关联，优先引用
0.7 – 0.8中等，谨慎参考
< 0.7不够相关，不推、不打扰
现在能做到 / 未来要做到（区分清楚，不画饼）
维度现在能做到未来要做到
找到哪一级整篇笔记——相关就整篇拿来参考文件内某段：音频某分钟 / PPT 某页 / PDF 某段
按什么匹配主题层面的语义相似度人物 / 项目等细粒度实体关联
靠什么支撑笔记正文本就是文本，直接可检索先把音视频 / 图片 / 文档转成可检索文本
细到"音频第几分钟、PPT 第几页"、人物 / 项目级关联，是规划方向，不是现在已做好的。检索范围 = 你的整个笔记库，存得越多、召回越准。
底线 · 宁可不帮，也不帮倒忙
可溯源

每段都标来源

用到的每一条都标出处、能点开核对原文，不想用一键去掉，正文实时重写——不黑箱、用户能管。

不打扰

不相关就不用

库里没有足够相关的（分数 < 0.7），就只用你当场写的，不硬塞、不编造。

05
怎么算赢 · 指标
做没做好不靠感觉，只看三个数
指标现在要做到
只打字用户的 AI 触达率几乎碰不到（藏在二级页）打开笔记就能用上，大幅提升
第一篇 AI 采纳率—给的建议 / 成稿被留下的比例，设目标
空笔记 → 成稿转化率—进来是空页、最后存成一篇的比例
三个数直接对应判断：触达率证明"够得着"，采纳率证明"帮得对"，转化率证明"真生出了第一篇"。（目标值待定）
06
说了算 / 说了不算
分清自己能定的，和必须拉通别人的——边界先框死
我们自己说了算（先做）
  • 入口前置：AI 从二级页搬到正在写的地方
  • 没写给起手式，写了给工具条
  • 克制策略：看不准不弹、速记不打扰
  • 成文呈现：引用标源、可核对、一键去掉
    • 说了不算，要拉通别人
  • 记忆调用范围多大、用户怎么管（依赖 MiClaw）
  • "边说边出字"的延迟与功耗代价，能不能接受
  • 工具条识别准确率的底线在哪（看错比不给更糟）
  • 关联笔记自动关联，关错了怎么纠
    • 明确不做：笔记 / 资料自动分类（已叫停）· 把这篇另做成 PPT / 播客 / 网页（属下游）· 给纯速记硬塞建议 · 把帮助继续藏二级页 · 纠结按钮怎么摆。
    一条规则贯穿全篇：没写帮你开始，写了帮你写下去、改好；而且越写越用上你的资料和历史。只打字的用户第一次在空白笔记就能用上 AI——记得越多，写得越像你，越离不开。
