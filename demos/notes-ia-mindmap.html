笔记APP · 信息架构

按用户行为拆解：记 → 看 → 用 → 管 → 找 ｜ 找 = 跨系统能力输出（小爱/MiClaw检索笔记数据）

  • 笔记
    • 记（内容怎么进来）
      • 主动记录 用户有意识地打开APP记
        • 手写/键入 入口：首页+号 打开编辑器 → 写文字
        • 录音 入口：首页+号/AI键 会议/课堂/随身
        • 拍照+写 入口：首页+号 图文混排记录
      • 自动采集 系统帮你记，用户无需主动打开笔记APP
        • 📞 通话录音 NEW 挂断后自动生成通话笔记
        • ⌚ 穿戴录音 NEW
          • 手表
          • 手环
          • 戒指
          • 磁吸支架
          • 耳机（待定）
          • 眼镜（待定）
      • 记忆迁入 小爱迁移 原小爱记忆数据迁移到笔记APP内管理
        • 🔗 链接收藏 小红书/大众点评等APP收藏存入
        • 🪪 卡证识别 AI键识屏 → 身份证/护照/银行卡
        • 📍 地址存储 语音/识屏 → 收货地址/常去地点
    • 看（内容怎么消费）
      • 看原文 入口：首页点击笔记
        • 笔记详情页 · 正文区 文本/录音回放+转写/图文
        • 通话详情 · 完整录音+转写 NEW
        • 穿戴详情 · 录音段回放 NEW
      • 看AI加工结果 入口：笔记详情页 · AI纪要区
        • 会议纪要（结构化摘要）
        • 课堂笔记（知识点梳理）
        • 通话纪要（关键信息+行动项） NEW
        • 穿戴摘要（去口语化） NEW
        • 链接摘要（文章要点提取）
      • 消费产出物 入口：笔记详情页 · 产出物卡片 / 待定列表页
        • 🎙️ 听播客 播放器 → 通勤/运动/做饭
        • 📊 看PPT 全屏翻页 → 汇报/分享
        • 🧠 看脑图 展开收起 → 理清结构
        • 🃏 翻知识卡片 逐张翻阅 → 记忆/速查
        • 📝 做考点/模拟题 复习模式 → 期末/检验
        • ✅ 查待办 入口：首页右上角 勾选/到期提醒
      • 查看记忆 入口：笔记APP内独立入口 小爱迁移
        • 🔗 链接列表 → 点开看摘要/原文
        • 🪪 卡证详情 → 结构化字段展示
        • 📍 地址列表 → 复制/导航
    • 用（内容怎么再创作）
      • AI生成产出物 AI 入口：笔记详情页 · AI对话框
        • "生成播客" 基于当前笔记 → 音频
        • "做PPT" 会议笔记/任何笔记 → 演示文稿
        • "生成脑图" 任何笔记 → 结构化脑图
        • "提炼考点"/"出题" 课堂笔记 → 复习材料
        • "生成卡片" 基于当前笔记 → 知识卡片
        • 自动提取待办 会议/通话纪要 → 待办清单
      • 手动编辑 入口：笔记详情页
        • 修改笔记正文
        • 追加内容
        • AI改写/续写 AI
      • 分享
        • 发送笔记
        • 分享产出物（播客/PPT/卡片）
        • IM直发 暂不支持
    • 管（内容怎么组织）
      • 笔记管理 入口：首页长按/详情页更多
        • 文件夹 → 新建/移动/删除
        • 置顶
        • 删除笔记
        • 撤销（AI修改回滚）
      • 产出物+待办管理 入口待定，设计侧调整中
        • 待办：完成/未完成切换
        • 待办：同步日历
        • 待办：到期催促 暂不支持
        • 待办：重复属性 暂不支持
        • 播客/PPT/卡片列表管理 入口待定
        • 产出物 ↔ 来源笔记 双向跳转
      • 记忆管理 入口：笔记APP内 小爱迁移
        • 查看/删除记忆条目
        • 按分类浏览（链接/卡证/地址）
        • 记忆详情 → 编辑/补充
    • 找（数据被检索消费） 跨系统能力：笔记提供数据，小爱/MiClaw来搜
      • 笔记内搜索 入口：首页右上角搜索
        • 关键词搜索 标题+正文+转写文本
        • 按时间筛选（日/周/月）
        • 按类型筛选（录音/图文/通话/穿戴）
      • 小爱/MiClaw检索 AI 笔记作为数据源，被外部系统调用
        • 语义搜索（自然语言理解意图）
        • 问答（直接给答案，不是结果列表）
        • 检索范围：笔记 + 通话 + 穿戴 + 记忆 + 产出物
      • 典型场景
        • "上周开会说了什么" → 从会议笔记答
        • "我老伴身份证多少" → 从记忆·卡证答
        • "李总电话里说几号来" → 从通话笔记答
        • "跑步时说的那个产品想法" → 从穿戴笔记答

附：笔记详情页 · 信息分区示意

设计师核心交付页面——一篇笔记打开后，从上到下看到什么

第一层级 · 原文
用户自己记的原始内容：标题、录音、转写、手写文字
通话笔记/穿戴笔记也展示在这里
手写感想/图文记录本身就是最终产物
第二层级 · AI纪要
AI自动生成的结构化内容：纪要/摘要/待办提取
用户不会反复看，但作为转化产出物的素材
中间态 = 拿到后还要再做事
AI对话框 → 生成第三层级产出物
底部「总结、润色、对话...」= 触发生成产出物的入口
点击后触发：生成播客/做PPT/生成脑图/提炼考点
产出物生成后跳转到独立详情页消费
页面信息优先级
① 用户原文永远在最上面（用户自己的东西优先）
② AI加工结果紧随其下（辅助理解）
③ 产出物入口在底部（需要时触发，不干扰阅读）
