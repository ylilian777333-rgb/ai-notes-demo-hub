空白笔记 0→1：帮用户写出第一篇能用的笔记

用户打开一篇空白文字笔记，常常对着白板不知从哪下手；而我们的 AI 又全藏在二级页，只打字、不用语音的人，几乎碰不到它。本稿只解决一件事——不用切到别的页面，顺着你已经写的，帮你最快写出第一篇能用的笔记。
按这条线往下读：用户卡在哪 → 服务谁 → 六个人的共性 → 进来怎么帮 → 怎么帮你写得更好 → 怎么衡量 → 边界和依赖在哪。

02
找共性 · 六个人只差一件：进来时手上有多少东西
不按"用户是谁"分，按"进来时手上有多少东西"分——这决定 AI 该怎么帮
六个人看着在做不同的事，其实只差一件——进来时手上有多少东西。同一个人不同时刻也不一样：林姐速记时手上是空的，小王记完想法是半句，大磊想写稿是一个题目。
情况一

空着，什么都没写

打开一篇空笔记，想记点什么，但不知道从哪开始——这是每个人进来的第一秒。
代表：大磊面对空白那刻 · 多数人进来的第一秒
AI 该帮 → 给个开头：几个起手式，或让他直接开口说
情况二

只有一句话主题

心里有个明确题目，但正文还没写。把这句话给 AI，就能要到一整篇。
代表：大磊"写开场白" · 小王把想法说成一句
AI 该帮 → 直接写一篇：一句话出整篇，或先给大纲
情况三

写了一半（最高频）

已写了些——一句灵感、几条提纲、一段流水账，差的是"接着往下"和"理顺"。
代表：小王的灵感 · 陈老师的提纲 · 阿哲的流水账
AI 该帮 → 接着往下写：顺着已写的扩写 / 补全 / 理顺
情况四

贴了一大段

把外部一大段贴进来，原始、读不进去，要 AI 帮忙提炼或换个形式。
代表：小悠粘贴课本 / 摘抄资料
AI 该帮 → 帮你提炼：总结 / 划重点 / 转问答 / 转表格
林姐是例外，要单独对待：她"空着"不是卡住，而是只想快速记一笔——本方案的生成建议不服务她。速记要的就是快，AI 只在认出电话 / 地址 / 时间时给个轻动作，别弹生成建议去打扰她。
一条规则：把四种情况，对到三个时刻
分水岭只有一个：你写了没有。没写——给起手式，帮你开始；写了——工具条看你写了什么，帮你写下去、改好。四种情况，就这一条规则。
进来时手上有什么怎么触发对应时刻AI 给什么
① 空着起手式 / 语音（纯速记除外）帮你开始一句引导 + 起手式 + 开口说
② 一句话主题工具条看你写了什么帮你写下去直接成稿 / 先列大纲
③ 写了一半工具条看你写了什么帮你写下去扩写 / 补全 / 理顺
④ 贴了一大段工具条看你写了什么帮你改好总结 / 划重点 / 转格式
所以下一节的三个时机，就是这条规则的展开：① 靠起手式（你还没写）；②③④ 靠同一套工具条（看你写了什么给下一步）。

一旦你写起来，工具条就接手：盯着你写了什么，给"写下去 / 改好"的下一步。下面三张卡，就是这三个时刻分别怎么帮。

① 帮你开始

给个开头

手上：空着
  • 空页中间给一句引导，不再一片空白
  • 给几个起手式：写一段 / 列清单 / 记要点
  • 语音做成最显眼的入口，进来就能说
② 帮你写下去

顺着已写的往下

手上：一句主题 / 写了一半
  • 一句话 → 直接成稿 / 先给大纲
  • 顺着已写的扩写、补全遗漏
  • 把流水账理顺成条理
③ 帮你改好

选中就改

手上：贴了一段 / 写完一段
  • 总结 / 划重点 / 转问答表格
  • 精简 / 换成正式语气
  • 选中哪段就改哪段
②③④ 用的是同一套工具条——它一直跟着你写的东西变：没写完帮你写下去，选中一段就帮你改好。不是一堆按钮，是"看你在干嘛、给下一步"。
04
怎么帮你写得更好（上）· 用上你自己的内容
同样是 AI 写，写得"好不好、像不像你"，差在有没有用上你自己积累的内容
把一篇笔记写好，光靠当场打的字不够。你存过的资料、AI 记住的关于你的事，写的时候都会被拿来帮你——你的旧笔记、录音、文档，加上 AI 对你的了解，存进来的越多，越能帮你写好。
可用的内容具体是什么帮你把这篇写好在哪一面
你存过的内容同主题旧笔记 / 文档、录音 & 通话转写、播客 / PDF / 网页有内容可引、有据可查
AI 对你的了解你是谁 / 角色 / 偏好、写作习惯、项目与协作关系写出来像你、贴合你
此刻的情境时间 / 地点 / 日程 / 最近在忙什么对得上当下场景
这些内容都是你自己一点点积累下来的。积累得越多，AI 写出来越贴合你、越难被替代——这是笔记区别于通用工具的长期价值。所以让录音、文档、记忆都沉淀进笔记，不是为了存着，是为了把每一篇都写得更好。
内容不用一次全接，按"对写作帮助多大"排优先级：先接最高频、最相关的（旧笔记 + 记忆 + 录音转写，P0）；其次按需接播客 / PDF / 网页（P1）；图片 OCR、情境信号等长尾后置（P2）。本质是——存得"相关"比存得"多"重要，检索不到的内容对写作零贡献。
05
怎么帮你写得更好（下）· 这些内容怎么被用上
落地机制：先理清"写好 = 三层"，再看你的内容具体怎么用进去
先说清楚——"把一篇写好"不是两招就够，是三层叠起来的：
① 底子：AI 把话写通顺、结构清楚，并按你在工具条选的意图来（扩写 / 总结 / 成稿，见上一节）。这层大家都有，只靠它，写出来是一篇"通顺的通用范文"。
② 有据：引用你存过的内容（检索引用）。
③ 像你：用对你的了解（背景注入）。
②③ 才是把通用范文变成"你的"那一篇的关键——本节讲透的就是这两层。
一句话分工：① 让它"读着顺"，②③ 让它"是你的、信得过"。只引用不了解你，像拼凑的资料；只了解你不引用，像空谈；三层都缺，就是你现在"对着白板自己憋"。
②③ 两层怎么落地 · 各管一件事
用法用到什么怎么用进这一篇用户能不能管
检索引用
让它有据		同主题旧笔记 / 录音转写 / 文档 / PDF找出相关片段、引进正文，并逐条标上来源能：点开核对原文、一键去掉
背景注入
让它贴合你		你是谁 / 角色 / 偏好、写作习惯、项目与协作关系作为底色带进去，影响语气、措辞、详略，不逐条标"引用自记忆"能：在设置里管理记忆范围
两者分工清楚：检索引用解决"有没有内容、对不对"——看得见、标得出；背景注入解决"像不像你写的"——是底色，融在字里行间。
检索引用怎么"引得准"：相关性怎么算
取这篇笔记开头约 500 字当查询，AI 搜索做"主题层面的语义相似度"匹配，返回候选 + 相关性分数，按分数取用。复用现有 AI 搜索能力，不新造一套。
相关性分数怎么处理
> 0.9确定关联，直接引用
0.8 – 0.9强关联，优先引用
0.7 – 0.8中等，谨慎参考
< 0.7不够相关，不引、不打扰

怎么算赢 · 三个指标
做没做好不靠感觉，只看三个数
指标现在要做到
只打字用户的 AI 触达率几乎碰不到（藏在二级页）打开笔记就能用上，大幅提升
第一篇 AI 采纳率—给的建议 / 成稿被留下的比例，设目标

07
边界与依赖 · 不做什么、要拉通谁
最后框死：哪些我们自己能定、先做，哪些要拉通别人，哪些明确不做
我们自己能定 · 先做
  • 入口前置：AI 从二级页搬到正在写的地方
  • 没写给起手式，写了给工具条
  • 克制策略：看不准不弹、速记不打扰
  • 成文呈现：引用标源、可核对、一键去掉
    • 要拉通别人才能定
  • 记忆调用范围多大、用户怎么管（依赖 MiClaw）
  • "边说边出字"的延迟与功耗代价，能不能接受
  • 工具条识别准确率的底线在哪（看错比不给更糟）
  • 关联笔记自动关联，关错了怎么纠
    • 明确不做：笔记 / 资料自动分类（已叫停）· 把这篇另做成 PPT / 播客 / 网页（属下游）· 给纯速记硬塞建议 · 把帮助继续藏二级页 · 纠结按钮怎么摆。
    一条规则贯穿全篇：没写帮你开始，写了帮你写下去、改好；而且越写越用上你存过的内容和历史。只打字的用户第一次在空白笔记就能用上 AI——记得越多，写得越贴合你。
