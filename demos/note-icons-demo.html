笔记首页底部 Icon 方案对比

左：导入富媒体 | 中：语音笔记（主入口）| 右：新建文字笔记

当前方案
导入icon + 麦克风 + 加号
问题：左侧"导入"icon辨识度低，右侧"+"含义模糊（新建什么？）
导入
语音
新建
- "导入"icon像退出/分享，用户不知道是上传文件
- "+"太泛，没传达"文字笔记"
方案A：图标直觉化
相册/文件icon + 麦克风 + 文档icon
用具象图标替代抽象符号，一眼看懂功能
图片/文件
语音
文字笔记
+ 图片icon=上传文件，文档icon=写文字，认知负荷低
- 图片icon可能让用户以为只能传图片
方案B：文字标签
icon + 文字标签组合，彻底消除歧义
在图标下方加文字说明，新用户也能理解
上传
说话记录
写笔记
+ 文字标签完全消除歧义
+ "上传"、"说话记录"、"写笔记"直白易懂
- 底栏视觉稍拥挤
方案C：差异化形态
胶囊按钮 + 圆形主按钮 + 方形按钮
通过按钮形状区分功能类型，不依赖图标识别
导入
写
+ 形态差异大，三个按钮完全不同不会混淆
+ 语音是圆形主按钮，视觉优先级最高
- 视觉风格较新，需要适配设计语言
方案D：功能暗示icon
文件夹+箭头 + 波形 + 笔
每个icon暗示操作结果而非操作方式
从文件
说话记笔记
手写
+ 文件夹+箭头=从文件导入，笔=手写/打字，语义清晰
+ 中间按钮笔记形态+音波暗示"说话变笔记"
- 中间icon稍复杂
方案E：极简+颜色区分
统一圆形，用颜色和最简icon区分
三个功能用三种颜色，icon极度简化
上传
录音
文字
+ 颜色区分一目了然：蓝=上传，橙=语音，绿=文字
+ 极简，学习成本最低
- 需要设计系统支持多色icon

方案对比总结

方案 核心思路 辨识度 美观度 适合场景
A 图标直觉化用具象图标高高图标语言成熟的用户
B 文字标签icon+文字双保险最高中新用户多/功能不熟悉
C 差异化形态按钮形状区分高高设计语言灵活的产品
D 功能暗示icon暗示操作结果中高中功能明确的工具型产品
E 极简+颜色颜色分类+极简icon高最高追求极简美感的产品
