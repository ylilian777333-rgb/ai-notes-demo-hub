05 · SCENE FLOWS
场景串联：端到端怎么转
🎓 场景一：学生上课
用户画像：18-24岁大学生，每天2-4节课，需要高效记录+复习备考
阶段用户做什么系统做什么产出
课前点提醒卡片 / 打开笔记日历识别课程→推送提醒→自动新建今日笔记—
课中录音 + 拍PPT/板书 + 标记重点实时转写 + 照片按时间线关联—（数据积累）
课后无需操作AI转写→分章节→生成总结→照片OCR融入→提取作业课堂笔记 + 待办
复习"帮我复习高数" / 打开合集跨多节课笔记汇总→生成考点清单→出模拟题→生成播客考点 + 模拟题 + 播客
飞轮效果：学生记了一学期课 → 期末说"帮我复习" → AI基于整学期积累产出完整复习方案。
这是NotebookLM做不到的——它需要手动喂文档，我们全程自动积累。
💼 场景二：会议记录
用户画像：25-35岁白领，每周3-5次会议，需要高效跟进待办
阶段用户做什么系统做什么产出
会前—推送：会议名+参与人+上次遗留待办—
会中录音 + 拍白板 + 标记关键决策录音+照片按时间线关联—（数据积累）
会后无需操作按议题生成纪要→提取待办→同步日历→上岛通知会议纪要 + 待办
跨次回忆"上次会定了什么"MiClaw检索历史会议笔记→精准回答+附来源精准回答
飞轮效果：开了10次产品评审会 → 问"张总这个月都提了什么意见" → AI从10篇纪要中跨篇聚合回答。数据越多越有用。
📱 场景三：日常速记（AI键 / 随口记）
用户画像：任何小米手机用户，日常碎片化记录
触发用户做什么AI 处理产出
QQ群老师发作业按AI键识别为待办→提取科目+内容+截止时间待办（晚上问"今天作业"直接答）
小红书好文按AI键抓链接全文→AI摘要→保留原链接后台沉淀（问的时候调出来）
走路想到idea长按AI键说话录音+转写+AI摘要+含待办自动生成语音笔记（首页可见）
微信收到体检PDF分享到笔记解析PDF→提取关键指标→结构化存储后台沉淀（问"血糖多少"直接答）
关键规则：
· 短按AI键存的 → 后台沉淀，首页不展示，归到"AI速记"合集
· 长按AI键语音笔记 → 首页展示，因为这是用户主动创作
· 分享面板存的文件 → 后台沉淀，MiClaw搜索能搜到
06 · ACCESS METHODS
"怎么用"——五种调用方式
用户不需要学"怎么搜笔记"。资产积累后，五种方式自然触达：
1
直接命中

"我血糖怎么样" → 直接答
2
自然语言

"今天作业是什么" / "上次会议定了什么"

3
智能补全

4
系统主动提醒

出发前一天→上岛"明天CA925去东京，08:30起飞"

有时间属性的行程/待办
5
笔记内"跟AI聊"

打开某篇笔记→点按钮→基于这篇内容深度对话

正在看某篇想讨论/扩展
